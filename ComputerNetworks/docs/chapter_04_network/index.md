# 第4章 网络层

网络层的目标是把数据报从源主机送到可能跨越许多异构网络的目的主机。IP 提供统一地址和尽力交付；路由协议计算可用路径；每台路由器依据本地转发表完成下一跳选择。

## 本章地图

- [IPv4、子网与地址规划](01_ip_addressing_subnetting.md)：CIDR、前缀、子网、DHCP 与聚合。
- [IPv6、NAT 与 ICMP](02_ipv6_nat_icmp.md)：地址空间演进、地址转换、差错报告与诊断。
- [转发与路由](03_forwarding_routing.md)：数据平面与控制平面、最长前缀匹配和路由算法。

## 服务模型：尽力而为

IP 不承诺可靠、顺序、固定时延或带宽，只尽力把每个数据报送往目的地。这个看似“弱”的服务模型是互联网能连接异构链路的重要原因：网络核心不必理解每个应用的可靠性需求，端系统可以按需使用 TCP、QUIC、冗余或实时策略。

代价是失败必须被上层看见和处理。数据报可能因队列溢出、无路由、跳数耗尽、MTU 不合适或策略过滤而消失。ICMP 提供部分反馈，但发送方不能假设每次失败都一定收到错误消息。

## 学习目标

完成本章后，应能：

1. 从 CIDR 前缀计算网络范围并设计小型子网。
2. 解释私有地址、默认网关、DHCP 和 NAT 的关系。
3. 读写常见 IPv6 压缩形式。
4. 用最长前缀匹配手工选择出接口。
5. 区分路由协议“算路”与路由器“按表转发”。

!!! tip "一个稳定直觉"
    路由器通常不为数据报计算完整端到端路线。它只根据目的前缀选择下一跳；下一台路由器重复相同动作。全局路径是许多局部决定共同形成的。
