# 第5章 链路层与局域网

网络层描述跨网络的尽力交付，链路层负责相邻节点之间的一跳传输。不同链路差异很大：以太网交换机连接有线设备，Wi-Fi 终端共享无线信道，广域点到点链路又有不同封装。IP 能建立统一互联网，正是因为每一跳都可以选择适合自己的链路技术。

## 本章地图

- [差错检测与介质访问](01_error_detection_mac.md)：帧为何需要校验，共享信道如何避免所有节点同时发送。
- [以太网、Wi-Fi 与 ARP](02_ethernet_wifi_arp.md)：交换、地址学习、无线接入和 IPv4 邻居解析。

## 本章的两个 MAC

`MAC` 常同时指：

1. **Media Access Control**：介质访问控制，决定共享信道上谁何时发送。
2. **MAC address**：链路层地址，用于局域网帧的一跳交付。

两者相关但不是同义词。一个协议可以讨论介质访问规则，也可以讨论地址格式和帧转发。

## 学习目标

完成本章后，应能：

- 解释校验和与 CRC 能检测什么、不能保证什么。
- 比较信道划分、随机接入和轮流接入。
- 解释交换机如何从源 MAC 自学习转发表。
- 画出主机访问异网段服务器时 ARP 的真实目标。
- 解释 Wi-Fi 为什么不能简单照搬早期以太网的碰撞检测。

!!! question "开始前的自测"
    主机访问互联网网站时，ARP 查询的是网站服务器地址吗？通常不是。若目的 IP 不在本地子网，主机查询默认网关的链路层地址，把这一跳的帧先交给网关。
