# 第2章 信息表示与数字逻辑

机器不能直接保存“数”“字母”或“指令”，只能保存有限位模式；电路也不会理解数学定义，只会对逻辑电平作变换。信息表示回答“位模式是什么意思”，数字逻辑回答“位模式怎样被计算和记住”。

## 本章内容

- [数制、补码、浮点数与字符](number_representation.md)：理解同一串位如何按不同规则解释，以及有限精度的边界。
- [布尔逻辑、组合电路与时序电路](digital_logic.md)：从逻辑门搭出加法器、选择器、寄存器和状态机。

## 两条主线

第一条是**编码**：建立数学对象或符号与位串之间的映射。编码方案决定范围、精度、运算便利性和异常值。

第二条是**状态**：组合电路只根据当前输入给出输出，时序电路还记住过去。没有状态，就没有寄存器、程序计数器，也没有“执行到第几条指令”。

## 最小例子

8 位模式 `11111111` 没有脱离上下文的唯一含义：

- 作为无符号数是 $255$；
- 作为补码整数是 $-1$；
- 作为某些单字节字符编码可能是一个扩展字符；
- 作为指令的一部分，可能只是操作码或立即数字段。

硬件保存的是位，解释来自接口契约。
