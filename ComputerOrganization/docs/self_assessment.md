# 综合自测

## 检验真懂的最好办法：合上笔记，把因果链讲给别人听

做这份自测之前，先别急着逐题刷完。挑一个你最有把握的场景——从「地址」「状态」和「性能代价」里各抽一道题——试着在白纸上边画边讲给一位虚构的听众听：某个数值究竟是由哪个硬件部件算出来的？下一拍写到了哪里？如果把其中一个前提条件改掉（比如把命中改成未命中、把单核改成双核），整条链路又会怎样连锁反应？

只要讲得卡壳了，就是最好的查漏补缺信号：卡在地址与数据流向时，回头重走一遍[数据通路与指令周期](chapter_04_cpu/datapath_instruction_cycle.md)；卡在加速比与阶段瓶颈时，重温[性能公式与 Amdahl 定律](chapter_07_io_parallel/performance_amdahl.md)。

这组题目绝不考死记硬背的术语定义，而是专攻**跨层推理**：检验你能不能把第 2–3 章的位编码与逻辑电路、第 4 章的指令集与调用约定、第 5–6 章的数据通路与流水线、第 7–8 章的缓存与虚拟内存，乃至第 9–10 章的 I/O、多核一致性与 GPU 拓扑，顺滑地拧成同一条因果链。建议每道题都先口述直觉、再画出状态与数据流、最后落笔算数值。

## 第一关：概念贯通（用自己的话讲透「为什么」）

1. **补码的智慧与代价**：为什么二进制补码能让硬件用同一套加法器统一处理加减法？这套优雅设计付出了什么范围上的不对称代价？
2. **契约与实现**：指令集架构（ISA）和微体系结构究竟划清了什么边界？为什么同一份编译好的 RISC-V 程序，可以在从极简单周期芯片到复杂超标量乱序芯片的多代处理器上无缝运行？
3. **无记忆到有记忆**：组合电路和时序电路最本质的分水岭是什么？在漫长的组合逻辑关键路径中间插入一排寄存器，为什么既能切分出更高的主频、又拉开了流水线的序幕？
4. **局部性的赌注**：缓存究竟是赌程序的哪两种统计规律才得以用极小容量撑起近似主存的速度？如果某个程序的访存地址彻头彻尾均匀随机，缓存还剩下多少价值？
5. **解放 CPU 的双人舞**：中断与 DMA 分别替 CPU 卸下了哪一种沉重负担？为什么现代高速网卡与 NVMe 固态硬盘总是把两者配合使用？
6. **软硬合谋的虚拟存储**：为什么说虚拟内存既离不开操作系统，也离不开处理器硬件？如果缺少硬件的 TLB 和权限检查，纯靠软件模拟会撞上什么死墙？

## 第二关：硬核手算（拿纸笔一步步推出来）

### 1. 二进制补码算术

在 8 位二进制补码表示下，写出 $-37$ 的二进制编码，再将它与 $+50$ 直接送入 8 位加法器相加。请逐步写出「按位取反 → 加 1 → 相加 → 丢弃高位进位」的全过程，并判断这次运算是否发生了**有符号溢出**。

??? tip "核对提示"
    - $+37 = 0010\,0101_2$ → 按位取反得 $1101\,1010_2$ → 加 1 得 $-37 = 1101\,1011_2$；
    - $+50 = 0011\,0010_2$；
    - 相加得 $(1)\,0000\,1101_2$，丢弃第 9 位进位后低 8 位为 $0000\,1101_2 = +13$；
    - 一正一负相加结果必然落在 $[-128, 127]$ 内，**没有发生有符号溢出**（尽管产生了最高位进位——千万别把无符号进位误判成有符号溢出！）。

### 2. 缓存地址切分与组定位

某直接映射（1 路）缓存共有 16 组，每块大小为 16 字节，机器使用 32 位物理地址。
1. 请分别求出块内偏移（block offset）、组索引（set index）和标记（tag）各占多少比特；
2. 物理地址 `0x12345678` 会映射到哪一组？它的标记和块内偏移分别是多少？

??? tip "核对提示"
    - 块内偏移：$\log_2 16 = 4$ 位（低 4 位）；组索引：$\log_2 16 = 4$ 位（第 4–7 位）；标记：$32 - 4 - 4 = 24$ 位（高 24 位）。
    - 因为每 4 位二进制恰好对应 1 位十六进制，`0x12345678` 直接按十六进制位切分即可：最低位 `0x8` 是块内偏移（8），倒数第二位 `0x7` 是组索引（**第 7 组**），高 6 位十六进制 `0x123456` 就是标记！

### 3. 五级流水线时空排布

像[流水线、冒险与停顿](chapter_05_pipeline/pipeline_hazards.md)里的时空表那样，逐拍画出下面三条 RISC-V 指令在经典五级流水线（IF / ID / EX / MEM / WB）中的推进过程。假设硬件支持从 `EX/MEM` 和 `MEM/WB` 向 ALU 转发，但 `lw` 后紧跟立即使用其结果的指令仍需停顿 1 拍插入气泡：

```asm
lw  x5, 0(x10)
add x6, x5, x7
sub x8, x6, x9
```

??? tip "核对提示"
    - `lw` 与 `add` 之间存在 `load-use` 冒险：第 4 拍 `add` 在 EX 处插入 1 颗气泡（`--`），第 5 拍才进 EX 并从 `lw` 的 `MEM/WB` 接住转发来的 `x5`；
    - `add` 与 `sub` 之间是普通 ALU-to-ALU 的 RAW 相关：`add` 第 5 拍 EX 算出 `x6` 存入 `EX/MEM`，第 6 拍直接转发给 `sub` 的 EX，**无需再插气泡**！三条指令共在第 8 拍全部走完 WB。

### 4. Amdahl 定律天花板

某计算任务中，有 $70\%$ 的原始执行时间可以改写并行并加速 $5$ 倍，其余 $30\%$ 无法加速。
1. 优化后的整体加速比是多少？
2. 就算把那 $70\%$ 的部分加速到无穷快（耗时归零），整体加速比的理论上限是多少？

??? tip "核对提示"
    - $\text{Speedup} = \frac{1}{(1 - 0.7) + 0.7 / 5} = \frac{1}{0.3 + 0.14} = \frac{1}{0.44} \approx 2.27\times$；
    - 当 $s \to \infty$ 时，上限为 $\frac{1}{1 - 0.7} = \frac{1}{0.3} \approx 3.33\times$。

## 第三关：端到端综合追踪

设处理器执行一条 `lw x5, 8(x10)`，此时恰好撞上「三重冷启动」中的两重：这是该进程首次访问这一虚拟页，因此 **D-TLB 未命中**，同时对应的数据块也不在 **L1 数据缓存** 里；唯一庆幸的是，页表里该页的映射已经有效、权限可读，且页面本身就安安静静地躺在物理主存里（没有触发缺页异常）。

参照[页表、TLB 和一次访存](chapter_06_memory/virtual_memory_hardware.md)，请按严格因果顺序写出从取指（IF）出发，一直到把 32 位整数稳稳写进 `x5` 结束的全过程：
1. 每一步的输入、产出和经手的硬件部件分别是什么？
2. 哪几个步骤在现代处理器上可以巧妙重叠并行（例如 VIPT），哪几个步骤之间存在无法逾越的先后等待？

## 第四关：架构师设计题（没有唯一标准答案）

现在请你担任一颗超低功耗物联网传感器芯片的首席架构师。这颗芯片的目标工作负载非常鲜明：**控制分支极少、程序代码很小、对实时响应时间的可预测性（最坏情况延迟必须严格封顶）要求极高、供电来自纽扣电池，但并不追求惊人的峰值算力。**

面对下面四道经典的微体系结构选择题，请你分别拍板并把「性能、功耗、面积、最坏情况可预测性与软件复杂度」放进同一张权衡表里说明理由：

1. 执行骨架选**单周期**、**3–5 级短流水线**，还是 **15 级深流水线**？
2. 片上高速存储选**大容量多路组相联硬件缓存**，还是选一块由程序员或编译器明确安排「何时把哪些数据放进去」的小容量确定性本地存储——**便签存储**（scratchpad memory）？
3. 调度引擎选**复杂乱序多发射**，还是**简洁顺序单发射**？
4. 需不需要在芯片里加入**SIMD 向量指令单元**？（提示：这取决于传感器端是否需要做密集的滤波/轻量端侧信号处理，试分析正反两面！）

## 四级自评标尺

合上整套教程，拿下面四个台阶给自己打个分：

- **第一阶（能复述）**：认得术语、背得出公式，知道缓存、TLB、DMA、MESI 大致是什么；
- **第二阶（能计算）**：能徒手做完补码运算、缓存组索引切分、流水线时空图、AMAT 与 Amdahl 定律计算；
- **第三阶（能追踪）**：给一条指令或一批训练数据，能闭着眼睛指出沿途每一个状态部件、数据通路和等待点；
- **第四阶（能设计）**：面对一项陌生的新优化或新硬件，能立刻盘清它的收益、适用边界、付出的代价，以及优化后下一个冒出来的新瓶颈。

一旦踏上后三阶，这套知识就不再是一堆按章节贴好标签的死记硬背，而真正内化成了你脑海里一台**可推演、可迁移的活计算机模型**——今后哪怕面对十年后诞生的新架构、新加速器，你依然能一针见血地问出最关键的那几个问题。
