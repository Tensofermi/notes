# 复杂度分析

## 用同一组输入比较成本

拿长度 10、100、1000 的名单做[比较次数实验](performance_evaluation.md)。先用[增长速度](time_complexity.md)解释比较量，再用[反转列表](space_complexity.md)看内存花在哪里。比较次数和额外空间随输入变大的趋势，就是这一章说的**复杂度**。遇到函数调用自己的写法（递归），还要数[同时等待返回的调用](iteration_and_recursion.md)。
