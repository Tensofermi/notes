# 分治

## 每次分出去什么，又把什么合回来？

在[两半各找一个最大值](divide_and_conquer.md)的例子里先找出拆分、停止和合并。再用[二分查找](binary_search_recur.md)看只需解一半的情况，用[汉诺塔](hanota_problem.md)看两个小问题如何围绕一次关键操作。

![分治](../assets/covers/chapter_divide_and_conquer.jpg)

!!! abstract

    难题被逐层拆解，每一次的拆解都使它变得更为简单。
    
    分而治之揭示了一个重要的事实：从简单做起，一切都不再复杂。
