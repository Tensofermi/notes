# 动态规划

## 先学会写一句状态定义

**状态**是回答一道小题所需的标识。例如算「到第几级台阶有多少种走法」时，所在的级数就是状态。从[爬楼时重复计算](intro_to_dynamic_programming.md)开始，再试着[记录刚好够用的历史](dp_problem_features.md)。用[五格硬币表](dp_solution_pipeline.md)练习先确定哪几格可以直接填（边界），再决定其他格的计算顺序。读背包时，专门比较[只取一次](knapsack_problem.md)与[可以复用](unbounded_knapsack_problem.md)。
