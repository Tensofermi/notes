# 最短路径：从 BFS 到 Dijkstra 和 Bellman–Ford

**先修**：[图的表示](graph.md)、[BFS](graph_traversal.md)、[堆](../chapter_heap/heap.md)。

**读完能做**：按边权和问题范围选择算法，手算一次松弛，并能指出 Dijkstra 使用的关键条件。

## 同一张图，两种“近”

从 S 到 T，有一条直接边，代价 9；也可以走 S → A → T，两条边的代价分别是 2 和 3。按跳数，直接走只需一跳；按代价，绕路只需 5。BFS 把每条边当作同样的步长。边权不同时，要记录的是目前发现的**最小总成本**。

给每个点保存一个暂定距离。起点为 0，其余为无穷大。考察边 u → v 时，比较「已知到 v 的距离」和「先到 u，再走这条边的距离」。后者更小就更新距离和前驱。这一步叫**松弛**。记前驱便能从终点倒着恢复路径。

## Dijkstra 如何确定一个点

所有边权非负时，可以反复从未确定的点中取暂定距离最小的一点，再松弛它的出边。任何先绕到其他尚未确定点的路线，已经付出的代价至少和当前最小距离相同，之后的边代价还会继续累加。所以取出的距离可以确定下来。

| 操作 | A 的暂定距离 | T 的暂定距离 |
| --- | ---: | ---: |
| 从 S 出发，松弛两条出边 | 2 | 9 |
| 取出 A，再松弛 A → T | 已确定为 2 | 5 |
| 取出 T | 2 | 已确定为 5 |

实现时可用最小堆保存候选 `(距离, 节点)`。如果改小一个点的距离，可以把新条目压堆，弹出旧条目时和距离表核对并跳过。对邻接表和二叉堆，这种实现的时间上界可写成 $O(V+E\log(E+2))$，其中 $V$ 是点数，$E$ 是边数。

## 负权为何改变算法

把 S → T 改为 2，S → A 改为 5，A → T 改为 −8。T 会先以距离 2 出队，但经 A 的真实成本是 −3。Bellman–Ford 的做法是反复扫描所有边。若没有从起点可达的负环，一条最短简单路径至多有 $V-1$ 条边，扫描 $V-1$ 轮即可；若再扫一轮仍能降低可达距离，就检测到了可达的负环。它的时间为 $O(VE)$。

| 情况 | 先选 |
| --- | --- |
| 所有边等权，只关心走几步 | BFS |
| 所有边权非负 | Dijkstra |
| 边权可负，需要检查可达负环 | Bellman–Ford |

路由协议还要考虑每台设备拥有什么信息，以及链路变化后多久收敛。可以接着读<a href="../../ComputerNetworks/chapter_04_network/03_forwarding_routing.html">转发与路由</a>。

## 自测

把 A → T 的代价从 3 改为 7。S 到 T 的最小成本是多少？哪种做法能保留两条同成本路径？

??? note "参考思路"
    两条路线的成本都是 9。标准松弛记录一个前驱即可返回一条最短路，也可以在候选成本相同且已知有限时收集多个前驱。零权边可能使这个前驱关系含环，枚举路径时还需定义是否允许重复节点。
