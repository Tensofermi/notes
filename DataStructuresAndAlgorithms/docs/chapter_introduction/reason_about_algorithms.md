# 从问题到算法：先说清什么要保持成立

**先修**：会读变量、条件和循环。

**读完能做**：把一句需求写成可检验的输入、输出和约束，并用循环不变量解释一个算法。

假设站点收到了三个任务，提交时刻分别是 12、9、15。你要找最早的任务。输入是一列任务，输出是一个任务，约束是空表没有答案，时间相同取先出现在输入里的任务。明确最后一条，才知道比较时该用 `<` 还是 `<=`。

```python
def earliest(tasks):
    if not tasks:
        return None
    best = tasks[0]
    for task in tasks[1:]:
        if task["submitted"] < best["submitted"]:
            best = task
    return best
```

`best` 的**循环不变量**是：每次处理完一项，它都是已经检查过的任务里最早的一项，时间相同保留第一项。第一次处理前只检查了首项，条件成立。下一项更早就换掉，否则保留，条件继续成立。循环结束时，已经检查的集合就是整个输入。这个解释也暴露了空表需要单独处理的原因。

切片 `tasks[1:]` 在 Python 中会新建列表。这里用它突出循环逻辑。如果输入很大，可以迭代下标或使用迭代器，把额外空间降到常数。若应用需要反复取出最早任务，可以用[优先队列](../chapter_heap/heap.md)维护多个候选；单次查询仍可从线性扫描出发。

## 自测

输入的提交时刻为 12、9、9、15。逐项写出当前候选。如果条件改成 `<=`，最终保留哪一项？

??? note "参考思路"
    严格比较时保留第一个时刻为 9 的任务。改成非严格比较后，第二个时刻为 9 的任务会覆盖前一个。两种规则都找到最小值，但对应不同的并列约定。
