# 参考文献

## 中文视频选读

- **Krahets《Hello 算法》入门课**。先看查字典、整理扑克牌、找零钱怎样变成算法问题，再对照笔记的[迭代与递归](../chapter_computational_complexity/iteration_and_recursion.md)，自己画出调用的去程和回程。[算法无处不在](https://www.bilibili.com/video/BV16T421C7Au/) · [迭代与递归](https://www.bilibili.com/video/BV1hy411e7iZ/)
- **浙江大学《数据结构》**。陈越、何钦铭的课程可补看线性表、堆和图，选一讲「小白专场」跟着写 C 语言实现。B 站合集由第三方整理，授课大纲见原课。[B 站合集](https://www.bilibili.com/video/BV189BGBEERM/) · [浙江大学课程](https://www.icourse163.org/course/ZJU-93001)
