# 虚拟内存 { #4 }

## 拿纸画两张页表

两个进程都说「读 26 号地址」，却能分别读到自己的字节。26 是程序使用的**虚拟地址**，处理器要换算成内存中的**物理地址**才能取数。系统把虚拟地址按固定大小切成**页**，也把物理内存按相同大小切成**页框**，用**页表**记录每一页对应哪个页框。先用[16 字节小页](01_address_space_paging.md)手算一次，再[比较三种查找结果](02_page_tables_tlb_faults.md)，最后[选出该换掉哪一页](03_replacement_allocation.md)。

## 地址翻译主线

**TLB** 是处理器保存近期地址翻译结果的缓存。找到翻译叫命中。没找到缓存记录时，先查页表。如果页表也没有可用映射，或权限不允许这次访问，才通过**缺页异常**交给内核处理。

```text
CPU 产生虚拟地址
  -> TLB 命中：按权限检查，允许则用物理地址取数据
  -> TLB 未命中：查页表，有有效映射且权限允许则取数据
  -> 缺页异常：内核能补齐映射就重试，否则报告错误
```

## 与文件和 I/O 的连接

有些页的内容来自文件，可以把文件的内存副本（**页缓存**）直接映射给进程。另一些页用来保存堆、栈等运行中的数据，不对应某个文件，称为**匿名页**。内存不够时，未修改的文件页可以丢掉，再从原文件读取；已修改的文件页通常要先保存修改；匿名页可以移到磁盘上暂存内存数据的区域（**交换空间**）。下一章会把这些路径接到文件系统和块设备。
