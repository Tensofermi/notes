# 固体物理笔记

## 背景介绍

固体物理关心的是一个朴素但很深的问题：当大量原子按照某种规则聚集在一起时，为什么会出现晶体结构、声子、能带、金属导电、热容和各种宏观性质？单个原子的物理已经足够复杂，而固体真正迷人的地方在于“集体行为”：周期性让问题变得可以计算，相互作用又让材料表现出远超单个粒子的丰富性质。

这份笔记沿着固体物理课程的主线展开：先从晶体结构和倒格子建立空间语言，再讨论晶体结合与晶格振动，随后进入能带理论和金属电子论。读的时候可以始终抓住两条线索：一条是实空间中的结构与相互作用，另一条是倒空间中的波矢、布里渊区、色散关系和态密度。

## 阅读建议

如果是第一次系统复习，建议先把“晶体结构”和“倒格子”读顺，因为后面的声子、能带和衍射都会反复使用这套语言。公式较多的地方不要急着背，先弄清每个量属于实空间还是倒空间、描述的是原胞还是晶胞、对应的是声子还是电子。

读到晶格振动和能带理论时，可以把二者放在一起比较：声子谱是晶格振动的色散关系，电子能带是布洛赫电子的色散关系。很多看似不同的公式，其实都在做同一件事：从色散关系出发，得到模式密度或能态密度，再推到热学、电学等宏观性质。
