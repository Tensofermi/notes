# 第2章 均匀体系的热力学性质

在上一章对热力学基本概念回顾和梳理的基础之上，本章会用一些数学技巧，进一步讨论**基本热力学量(物态方程,U,S)、辅助量、响应量**之间的关系，并利用这些关系来处理均匀体系的具体例子(节流过程、热辐射、磁介质)，得到其热力学性质。总的来说，只有物态方程和某些响应量可以通过实验直接测量，因而亟需找到从其导出其他热力学量的方法，这便是本章的核心。
