# 第3章 单元体系相变

熟悉了热力学的基本概念和数学方法的基本操作之后，本章主要是利用变分的方法研究单元体系的热动平衡和相变问题(对于单元系，没有化学平衡的问题)。借用分析力学中的变分技巧研究热力学平衡和稳定的确十分有趣，相变问题还涉及到许多前沿问题，热力学从这一章开始有趣起来了。
