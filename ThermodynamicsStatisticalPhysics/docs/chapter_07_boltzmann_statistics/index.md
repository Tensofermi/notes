# 第7章 Boltzmann统计理论

本章主要研究定域系统或满足非简并条件的非定域系统(都服从玻尔兹曼分布)，讨论系统热力学量的微观表达式。首先，引入粒子配分函数并将基本热力学量与粒子配分函数建立联系。其次，求出不同系统的粒子配分函数(理想气体、黑体辐射、常见固体)，从而得到它们的热力学性质。
