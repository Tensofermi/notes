# 第8章 Bose/Fermi统计理论

对于定域系统或满足非简并条件的非定域系统，由于服从玻尔兹曼分布，故使用粒子配分函数求出各个热力学量。然而，对于弱简并或强简并的非定域系统，由于服从玻色分布或费米分布，需要引入一个新的函数，即巨配分函数。本章将延续前面对近独立子系的讨论，讨论玻色气体和费米气体，并研究Bose-Einstein凝聚等有趣的物理系统。
